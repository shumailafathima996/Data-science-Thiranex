## 🛠️ Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

## 📂 How This Repo Is Organized

Each `task-N-*` folder is independent and runnable on its own:

```
task-N-name/
├── data/            # Raw + cleaned/processed datasets
├── notebooks/        # Jupyter notebook walkthrough (executed, with outputs)
├── scripts/           # Standalone, reusable Python scripts
├── images/           # Generated charts and dashboards
├── requirements.txt
└── README.md          # Task-specific write-up
```

See each task's own README for full details, methodology, and key findings.
