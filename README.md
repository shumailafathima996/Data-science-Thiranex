## 📌 Task Summaries

### Task 1 — Data Cleaning & Visualization
Cleaned a raw, messy e-commerce sales dataset (missing values, duplicates, inconsistent formatting, outliers) and built a set of visualizations and a combined dashboard to surface revenue, regional, and customer rating insights.

### Task 2 — Predictive Modeling Using Machine Learning
Built a customer churn prediction model, training and comparing Logistic Regression, Decision Tree, and Random Forest classifiers. Evaluated performance with accuracy, precision, recall, F1, ROC AUC, confusion matrices, and ROC curves.

### Task 3 — Exploratory Data Analysis (EDA)
Analyzed a student performance dataset to uncover patterns and correlations between study habits, parental education, test preparation, and academic scores, presenting findings as a structured report with statistical summaries and visualizations.

### Task 4 — Real-World Data Project (Finance)
An end-to-end capstone project predicting loan default risk for a lending business — combining data cleaning, exploratory analysis, and predictive modeling (Logistic Regression vs. Random Forest) into one applied workflow, with business recommendations based on the results.
